# รายละเอียดไฟล์ในโปรแกรม GHP Management (ERP)

เอกสารนี้รวบรวมรายชื่อไฟล์และหน้าที่ของแต่ละไฟล์ภายในโปรเจกต์อย่างละเอียด เพื่อใช้ในการอ้างอิงและทำความเข้าใจระบบ

---

## 📂 Root Directory (โฟลเดอร์หลัก)
- **PROJECT_GHP_ERP_SUMMARY_FOR_NEXT_CONTEXT.md**: สรุปความคืบหน้าและฟีเจอร์ปัจจุบันของโปรเจกต์
- **PROJECT_SECURITY_AND_LOGIC_FLAWS.txt**: บันทึกรายการจุดอ่อนที่ต้องแก้ไขด้านความปลอดภัยและตรรกะโปรแกรม
- **GIT_BRANCHING_GUIDE.txt**: คู่มือมาตรฐานการแตกกิ่ง (Branch) ใน Git สำหรับทีมพัฒนา
- **server_commands.txt**: รวมคำสั่ง CMD/PowerShell ที่จำเป็นสำหรับการรันและจัดการ Server
- **package.json**: ไฟล์กำหนด dependencies และ scripts สำหรับโปรเจกต์ในภาพรวม

---

## 📂 Backend (`/backend`) - ระบบหลังบ้าน (FastAPI)
### ไฟล์หลัก (Main Logic)
- **main.py**: ไฟล์เริ่มต้นของระบบ (Entry Point) ที่รวบรวม Routers และตั้งค่า CORS/Static Files
- **database.py**: ตั้งค่าการเชื่อมต่อฐานข้อมูล (SQLAlchemy Engine & Session)
- **oauth2.py**: ระบบความปลอดภัย การสร้างและตรวจสอบ JWT Token เพื่อระบุตัวตน
- **hashing.py**: จัดการการเข้ารหัส (Hashing) รหัสผ่านพนักงาน
- **storage.py**: จัดการระบบจัดเก็บไฟล์ที่อัปโหลด (เช่น รูปถ่ายพนักงาน หรือหลักฐานการลงเวลา)
- **requirements.txt**: รายการ Library ของ Python ที่ต้องติดตั้ง
- **reset_attendance.py**: สคริปต์ยูทิลิตี้สำหรับลบข้อมูลเวลาทำงานเพื่อใช้ในการทดสอบระบบ

### โฟลเดอร์ Routers (`/backend/routers`) - จุดรับส่ง API
- **auth.py**: จัดการระบบ Login, Logout และการขอ Token
- **users.py**: จัดการข้อมูลผู้ใช้, การแก้ไข Profile และข้อมูลพื้นฐานพนักงาน
- **attendance.py**: หัวใจของระบบลงเวลา (Check-in/Out) และลอจิกการคำนวณการสาย (T1, T2, T3)
- **zkteco.py**: ระบบสื่อสารกับเครื่องสแกนใบหน้า/นิ้วมือ ZKTeco ผ่านโปรโตคอล ADMS
- **hr.py**: ระบบจัดการพนักงานชุดใหญ่ (เพิ่ม/ลด/แก้ไขข้อมูลพนักงานทั้งหมด)
- **payroll.py**: จัดการข้อมูลเงินเดือนและการคำนวณรายได้ (กำลังพัฒนา)
- **permissions.py**: จัดการบทบาท (Roles) และสิทธิ์การเข้าถึงฟีเจอร์ต่างๆ
- **access_control.py**: ระบบควบคุมการเข้าถึงทรัพยากรระดับลึก
- **projects.py**: จัดการข้อมูลโครงการหรืองานที่พนักงานได้รับมอบหมาย

### โฟลเดอร์ Models & Schemas
- **models/**: นิยามโครงสร้างตารางในฐานข้อมูล (SQLAlchemy Models) เช่น `User`, `Attendance`, `OTRequest`
- **schemas/**: นิยามรูปแบบข้อมูลสำหรับการรับ-ส่งผ่าน API (Pydantic Models) เพื่อตรวจสอบความถูกต้องของข้อมูล (Validation)

## 📂 Frontend (`/frontend`) - ส่วนติดต่อผู้ใช้ (Vue 3)
### ไฟล์หลัก
- **src/main.js**: ไฟล์เริ่มต้นของ Vue App
- **src/App.vue**: โครงสร้างหลักของหน้าจอ (Layout)
- **src/api.js**: ตัวกลางในการเรียกใช้ API จาก Backend (Axios Wrapper)
- **vite.config.js**: การตั้งค่าการ Build และ Server ของ Vite

### ส่วนประกอบหน้าจอ (Components - `/frontend/src/components`)
#### 1. ส่วนของพนักงาน (`/user`)
- **AttendancePanel.vue**: หน้าจอหลักสำหรับการลงเวลาเข้า-ออกงาน
- **OTRequestModal.vue**: หน้าต่างสำหรับกรอกคำขอทำงานล่วงเวลา (OT) พร้อมลอจิกคำนวณชั่วโมง
- **AttendanceDashboard.vue**: หน้าสรุปสถิติการมาทำงานรายเดือนของพนักงาน
- **UserProfile.vue**: หน้าจัดการข้อมูลส่วนตัวและเปลี่ยนรหัสผ่าน

#### 2. ส่วนของฝ่ายบริหาร/HR (`/shared` & `/admin`)
- **HRManagement.vue**: ระบบจัดการพนักงาน (เพิ่มพนักงาน, แก้ไขแผนก, ดูประวัติรวม)
- **AttendanceSettings.vue**: หน้าตั้งค่าเวลาเข้างานปกติ และช่วงเวลาผ่อนผัน (Grace Period)
- **AdminPanel.vue**: แผงควบคุมหลักสำหรับผู้ดูแลระบบ
- **UserManagement.vue**: จัดการบัญชีผู้ใช้งานในระบบ
- **AccessManagement.vue**: กำหนดสิทธิ์พนักงานแต่ละคน (ใครทำอะไรได้บ้าง)

#### 3. ระบบยืนยันตัวตน (`/auth`)
- **LoginForm.vue**: หน้าจอสำหรับเข้าสู่ระบบ
- **RegisterForm.vue**: หน้าจอสำหรับลงทะเบียนพนักงานใหม่
